THE SOLAR EXPORT - WEBSITE FILE GUIDE

FILES
- index.html: Home page and enquiry form
- materials.html: GI pipe, AC/DC wire, inverter, ACDB, DCDB and PVC pipe
- panels.html: Waaree and Adani solar panel ranges
- gallery.html: Local photo preview page
- contact.html: Contact and WhatsApp details
- style.css: Shared design for all pages
- script.js: Enquiry form, WhatsApp and gallery preview
- images/: Put website image files here
